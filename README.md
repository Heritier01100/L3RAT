
# Android Remote Control Tool

**Legitimate Remote Device Management for Android**

## ⚠️ Legal Notice
This tool is for **legitimate purposes only**:
- Managing your own devices
- Managing devices with explicit user consent
- Parental monitoring with children's knowledge

**Unauthorized monitoring is illegal!**

## Features
- 🔐 Secure web-based dashboard with login
- 📱 Real-time device monitoring
- 📍 GPS location tracking
- 📷 Remote camera access
- 🎤 Audio recording
- 📳 Device vibration control
- 🎮 Screen control (interfere)
- 📦 APK creation

## Quick Start

### 1. Install dependencies
python3 -m venv venv
source venv/bin/activate
pip install -r server/requirements.txt
python3 start_server_py
